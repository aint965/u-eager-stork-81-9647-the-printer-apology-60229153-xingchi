An entry for [The Printer Apology](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153) on make.fun: a program that writes one funny one-line apology note from an office printer (at most 120 characters) to `/output/entry.txt`.

The printer apologises for jamming on its user's resignation letter — it read the letter first, agrees with it, and kept a copy. For leverage.

Run with `node main.ts` (Node 22). The output directory can be overridden for local testing with `OUTPUT_DIR` or a first CLI argument.
